# web-image-upload-testing
Manual QA portfolio project covering functional, validation, boundary and negative testing of a web image upload feature.
# Web Image Upload Feature – QA Testing

## Project Overview

This project demonstrates manual testing of an image upload functionality
for a web application.

## Requirements

The feature allows users to:

- Upload one image
- Upload JPEG images only
- Upload images smaller than 10 MB
- Save an uploaded image
- Edit/replace an existing image
- Delete an existing image
- Continue without uploading an image
- Display an image icon when an image exists
- Hide the image icon when no image exists

## Testing Scope

The following testing approaches were applied:

- Functional Testing
- Negative Testing
- Boundary Value Testing
- File Validation Testing
- UI Validation
- Persistence Testing
- Error Handling



## Key Test Scenarios

Critical scenarios include:

- Successful JPEG upload
- File size boundary validation
- Unsupported file format validation
- Single-image restriction
- Image replacement
- Image deletion
- Image persistence after page refresh
- Continuing without an image
- Image icon visibility
- Corrupted JPEG validation
- File-extension validation
- Network/upload failure handling
